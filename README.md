# Decentralized Voting App using Web3

This project is a decentralized voting system built using **Web3.js**, **Solidity**, and **Remix IDE**. It leverages the Ethereum blockchain to securely cast and track votes, ensuring transparency and immutability of the voting process. The contract is deployed on the **Sepolia Testnet**.

## Features
- **Smart Contract**: A voting contract written in Solidity and deployed using **Remix IDE**.
- **Web3 Integration**: Interact with the deployed smart contract using MetaMask and Web3.js.
- **Vote Casting**: Users can vote for their chosen candidates directly from the frontend.
- **Secure & Transparent**: Blockchain-based, ensuring that votes are immutable and transparent.

## Technologies Used
- **Solidity**: Smart contract development
- **Remix IDE**: Used to write, compile, and deploy the smart contract
- **Web3.js**: Blockchain interaction with Ethereum
- **MetaMask**: Wallet integration for transaction signing
- **React**: Frontend for displaying candidates and voting options
